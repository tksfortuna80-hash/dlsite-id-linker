# DLsite ID Linker

Web ページに書かれている DLsite の作品番号（`RJ123456` など）を、クリックで作品ページを開けるリンクに自動で変える Chrome 拡張機能です。

> [!WARNING]
> **NSFW**：この拡張機能は、成人向けコンテンツを含む DLsite の作品ページへのリンクを生成します。

<img src="docs/popup.png" alt="設定画面" width="324">

## できること

- **作品番号を自動でリンクに**：ページ内の作品番号を見つけて、DLsite の作品ページへのリンクに変えます。リンクは新しいタブで開きます。
- **フロアごとに切り替え**：どのフロアの番号をリンクにするかを選べます。

  | フロア | 作品番号の例 | 初期設定 |
  |---|---|---|
  | 同人 | RJ123456 / RJ01234567 | ON |
  | 成年コミック・書籍 | BJ123456 / BJ01234567 | OFF |
  | PCソフト・美少女ゲーム | VJ123456 / VJ01234567 | OFF |

- **フロアが見分けられる**：リンクの下線がフロアごとに色分けされます（同人＝ピンク、書籍＝オレンジ、PCソフト＝青）。マウスを乗せるとフロア名も表示されます。
- **見た目はそのまま**：元の文字の見た目は変えず、下線が付くだけです。
- **小文字も OK**：`rj123456` のような小文字の表記にも対応します。
- **後から読み込まれる内容にも対応**：無限スクロールや、ページを切り替えずに中身が変わるサイトでも、新しく出てきた番号をリンクにします。
- **設定はすぐ反映**：設定を変えると、開いているページにもすぐ反映されます。OFF にしたフロアのリンクは元の文字に戻ります。

### リンクにしないもの

- すでにリンクになっている文字
- 入力欄、文字の編集エリア、プログラムコードの表示部分
- 番号の前後に英字や数字がくっついているもの（例：`XRJ123456`、`RJ1234567890`）
- DLsite のサイト内（もともとリンクがあるため）

## インストール

1. このページの「Code」→「Download ZIP」でダウンロードして展開する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、展開したフォルダを選ぶ
5. ツールバーのパズルアイコンから「DLsite ID Linker」をピン留めしておくと、設定を開きやすくなります

## 使い方

インストールすれば、あとは普段どおりページを見るだけで作品番号がリンクになります。

設定を変えたいときは、ツールバーの拡張機能アイコンをクリックします。

- **右上のスイッチ**：拡張機能全体の ON / OFF
- **フロアごとのチェック**：そのフロアの番号をリンクにするかどうか

設定は、同じ Google アカウントでログインしている Chrome の間で同期されます。

## フロアの追加・リンク先の変更

フロアの追加やリンク先 URL の変更は、`src/departments.js` を編集するだけでできます。書き方はファイル内の説明を参照してください。
